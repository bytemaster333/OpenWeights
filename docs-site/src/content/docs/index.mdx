# siahub

self-hostable, xet-compatible hub for large files. the standard
`hf` CLI works unmodified — set `HF_ENDPOINT` at a siahub deployment,
then `hf upload` / `hf download` as usual. bytes land on the sia
network, not s3.

## why

- unmodified hugging face client (no fork, no patch)
- decentralized byte storage via sia
- upload + download + model pages + api keys out of the box
- optional pointer-only mirror on huggingface.co for discovery
